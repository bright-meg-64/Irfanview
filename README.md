## 📖 About

IrfanView is a lightweight image viewer, editor and converter developed by Irfan Skiljan. It handles common photo formats alongside many niche graphic types, can resize, crop, rotate and convert whole folders at once, and supports slideshows, thumbnails and plug in extensions. The 2026 build keeps the interface compact while adding improved color handling and updated decoder support.

## 🛠️ Troubleshooting

| Problem | Solution |
| --- | --- |
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer closes without finishing | Make sure the file is fully downloaded, then run it again as administrator |
| App opens but shows missing formats | Install the plug in package during setup or from the download page |
| Thumbnails load slowly | Lower thumbnail size or disable thumbnail caching in options |
| Slideshow stutters on large folders | Reduce the number of items per folder or close other heavy apps |
| Settings not saved between sessions | Check that the INI file is writable and not blocked by a sync tool |
| Wrong file association after install | Re open the options dialog and re apply the association checkboxes |
